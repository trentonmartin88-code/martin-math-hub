Topic 3 • Expressions

Algebraic Expressions

Learn how variables represent numbers, how substitution works, and how the order of operations helps us find the value of an expression.

Lesson 3-5Lesson 3-6Lesson 3-7Topic ReviewAnchor ChartsVocabulary

Big Ideas

Variables represent numbers

A variable is a letter or symbol that stands for a number. Its value can change depending on the situation.

Substitution replaces the variable

To evaluate an algebraic expression, replace each variable with its given numerical value.

Order still matters

After substituting, use the order of operations just as you would with a numerical expression.

Lesson 3-5: Evaluate Algebraic Expressions

The goal is not just to “plug in a number.” Students must substitute accurately and then evaluate the resulting numerical expression in the correct order.

Core Procedure

Substitute → Order → Simplify

1Identify the value given for each variable.
2Substitute the value everywhere that variable appears. Parentheses can make the replacement easier to see.
3Use order of operations: exponents, multiplication/division, then addition/subtraction.
4Simplify until one numerical value remains. Check whether the answer makes sense in context.
Important Notation

A number beside a variable means multiply

3n = 3 × nIf n = 5, then 3n = 3(5) = 15.
ab = a × bIf a = 4 and b = 2.5, then ab = 4(2.5) = 10.
x² means x × xIf x = 3/2, then x² = (3/2)(3/2) = 9/4.
Common mistake: changing the order

For 8 + 3n when n = 4, substitute first: 8 + 3(4). Multiply before adding. The value is 20, not 44.

Common mistake: forgetting what the variable can represent

A variable can represent a whole number, decimal, or fraction. Real-world situations may place limits on reasonable values: a number of people should usually be a whole number, while a measurement may be fractional or decimal.

Lesson 3-6: Generate Equivalent Expressions

Equivalent expressions may look different, but they have the same value for every value that can be substituted for the variable.

Properties of Operations

Rewrite without changing the value

Commutative Propertya + b = b + a   and   ab = ba. You may change the order.
Associative Property(a + b) + c = a + (b + c). You may change the grouping.
Distributive Propertya(b + c) = ab + ac and a(b − c) = ab − ac.
Identity Propertiesa + 0 = a and a × 1 = a.
How to Justify Equivalence

Properties prove; substitution can test

1Look at the structure of both expressions.
2Use a property to rewrite one expression step by step.
3If both expressions rewrite to the same form, they are equivalent.
4To prove two expressions are not equivalent, one value that gives different results is enough.
DISTRIBUTE

4(2x + 3) = 8x + 12. Multiply 4 by both terms inside the parentheses.

FACTOR

12x + 6 = 6(2x + 1). The common factor 6 is divided out of both terms.

REORDER & REGROUP

3 + x + 7 = x + (3 + 7) = x + 10. Commutative and Associative Properties make the structure easier to see.

DISPROVE BY SUBSTITUTION

Compare 2(x + 4) and 2x + 4. If x = 3, the values are 14 and 10, so they are not equivalent.

Common mistake: distributing to only one term

In 5(x + 2), the 5 multiplies both x and 2. The equivalent expression is 5x + 10, not 5x + 2.

Lesson 3-7: Simplify Algebraic Expressions

Simplifying means writing an equivalent expression in a cleaner form. One major strategy is combining like terms.

Like Terms

Same variable part = like terms

Like terms2x and 7x are like terms. ½n and 3n are like terms. 5 and 12 are like terms because both are constants.
Not like terms2x and 2y are not like terms. x and x² are not like terms.
Combine coefficients3x + 7x = (3 + 7)x = 10x.
Simplifying Procedure

Organize, combine, check

1Use the Distributive Property first if parentheses need to be removed.
2Identify like terms by matching their variable parts.
3Use the Commutative/Associative Properties to place like terms together.
4Add or subtract the coefficients; combine constants separately.
BASIC

x + 5 + 2x + 2 = 3x + 7.

SUBTRACTION

9g − 2g + 4 = 7g + 4.

FRACTIONS

½n + ¾n + 2 = 1¼n + 2.

DECIMALS & DISTRIBUTION

2.5(x + 4) + 1.5x = 2.5x + 10 + 1.5x = 4x + 10.

Common mistake: combining unlike terms

You cannot combine 4x + 3 into 7x. The constant 3 does not contain x. You also cannot combine x with x².

Anchor Charts

≡

Equivalent Expressions

Different-looking expressions are equivalent when properties of operations show that they have the same value for every variable value.

3(x + 4) ≡ 3x + 12
D

Distributive Property

Multiply the outside factor by every term inside the parentheses. The property can also work in reverse to factor.

a(b + c) = ab + ac
LT

Like Terms

Like terms have exactly the same variable part. Combine coefficients, not the variables themselves.

4x + 7x = 11x
≠

Not Like Terms

Different variables or different exponents cannot be combined.

3x + 2y stays 3x + 2y   |   x + x² cannot combine
S→O→S

Evaluate an Expression

Substitute the given value. Follow the Order of operations. Simplify until one value remains.

4 + 2x, x = 6 → 4 + 2(6) → 16
×

Invisible Multiplication

When a number and variable are written together, multiplication is understood.

5a = 5 × a    |    2xy = 2 × x × y
²

Exponents After Substitution

Replace the variable first, then evaluate the exponent before other multiplication, addition, or subtraction.

3r², r = 2 → 3(2²) → 3(4) → 12
½

Fractions & Decimals Work Too

The same procedure works when the variable value is not a whole number.

2.5m + 1, m = 1.2 → 2.5(1.2) + 1 → 4

Worked Examples

WHOLE NUMBER

Evaluate 20 + 3r when r = 14.
20 + 3(14) = 20 + 42 = 62

DECIMAL

A rental cost is represented by 8.75h + 4.50. Find the cost for h = 3.
8.75(3) + 4.50 = 26.25 + 4.50 = 30.75

FRACTION

Evaluate ¾p + 2 when p = 8.
¾(8) + 2 = 6 + 2 = 8

EXPONENT

Evaluate s² + ½ when s = 3/2.
(3/2)² + 1/2 = 9/4 + 2/4 = 11/4 = 2¾

TWO VARIABLES

Evaluate 5a + 2b when a = 3 and b = 4.
5(3) + 2(4) = 15 + 8 = 23

CHECK THE STRUCTURE

Evaluate 6 + 4x² when x = 2.
6 + 4(2²) = 6 + 16 = 22. Square before multiplying by 4.

Vocabulary

VariableA letter or symbol used to represent a number.
Algebraic expressionA mathematical phrase containing numbers, operations, and one or more variables.
EvaluateFind the numerical value of an expression.
SubstituteReplace a variable with a specified numerical value.
CoefficientThe number multiplied by a variable. In 7x, the coefficient is 7.
ExponentA number showing how many times a base is used as a factor.
Equivalent expressionsExpressions that have the same value for every allowed value of the variable.
TermA number, variable, or product of numbers and variables separated by addition or subtraction.
CoefficientThe numerical factor multiplying a variable.
ConstantA term with no variable.
Like termsTerms with the same variable part, including the same exponents.
